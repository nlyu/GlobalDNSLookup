Global DNS Lookup

About

A focused DNS comparison tool

Global DNS Lookup helps developers compare A, AAAA and CNAME responses using representative network prefixes. It is intentionally small, account-free and designed for quick technical troubleshooting.

What the tool measures

Lookups are performed through public DNS-over-HTTPS resolvers with EDNS Client Subnet values. This provides a useful geographic simulation, but it is not the same as running a probe on every ISP in a country.
